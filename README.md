# DureSync (두레싱크) — 팀 프로젝트 AI 워크스페이스

> **두레(Dure)** — 마을 사람들이 서로의 일을 함께 돕던 한국의 전통 협동 공동체. 그 방식을 AI로 다시 만든 팀 워크스페이스예요.
> 약칭은 **Dure(두레)** 이고, 슬로건은 **Connect · Work · Grow** 입니다. 로고와 아이콘은 `docs/brand/` 에 있어요 (브랜드 색 `#3B82F6` · `#8B5CF6` · `#22D3EE`).

프로젝트 단위로 **워크스페이스(코드) · 회의록 · 캘린더 · 팀 채팅**을 한 곳에서 쓰고, 회의록과 채팅에서 AI가 일정(누가/언제까지)을 찾아 캘린더에 올려주는 협업 플랫폼입니다.

## ▶ 바로 실행하기

```bash
git clone https://github.com/opiniom/code-lounge.git
cd code-lounge
./run.sh          # Windows 는 run.bat 더블클릭
```

실행되면 브라우저가 자동으로 열립니다. 직접 열려면:

**http://localhost:8000/app**

- 처음 실행하면 `.env` 가 자동으로 만들어집니다. 키가 없어도 **게스트로 둘러보기**와 규칙 기반 일정 분석이 동작해요.
- 구글/네이버 로그인, Gemini AI 분석을 쓰려면 `.env` 에 키를 넣으세요 (`docs/social_login_setup.md` 참고). `.env` 는 git 에 올라가지 않습니다.
- 서버 API 문서: http://localhost:8000/docs
- 발표 자료: `presentation.html` (브라우저에서 바로 열기)

### 🔗 떨어져 있는 팀원 초대하기

초대 링크는 서버를 켠 컴퓨터 주소(`localhost`)로는 다른 사람이 열 수 없어요. 아래처럼 **공유 모드**로 켜세요.

```bash
./share.sh        # 임시 공개 주소를 만들어 줍니다 (cloudflared 가 있으면 사용, 없으면 ssh 터널)
```

1. 터미널에 나온 주소가 아니라, 내 컴퓨터의 `http://localhost:8000/app` 에서 로그인하세요.
2. 워크스페이스의 프로젝트 이름 옆 **[팀원 초대]** 를 누르면 초대 링크가 자동으로 만들어져요 (프로젝트를 새로 만들면 이 창이 바로 열려요). 복사해서 보내세요 (공유 주소로 자동 생성).
3. 팀원은 링크를 열고 **이름만 정하고 [초대 수락]** 하면 바로 참여합니다 (가입 불필요). 이미 계정이 있으면 로그인 후 수락.

- 공유 모드에서는 보안을 위해 **코드 실행·API 문서·개발용 로그인이 꺼집니다.** (코드 실행은 `./run.sh` 로 켠 내 컴퓨터에서만)
- 주소를 아는 사람은 누구나 접속할 수 있어요. 끝나면 `Ctrl + C` 로 닫으면 주소도 사라집니다.
- 컴퓨터가 꺼져 있으면 접속할 수 없어요. 항상 켜져 있어야 한다면 클라우드 배포가 필요합니다.


### 🏆 이벤트 · 공모전 자동 수집

서버가 켜져 있는 동안 **해커톤·공모전·개발자 행사**를 알아서 모아 주기적으로 최신화해요 (기본 6시간마다, 서버 시작 직후에도 한 번). 화면의 **[지금 새로고침]**으로 바로 갱신할 수도 있어요 (로그인 필요, 5분에 한 번).

| 출처 | 내용 |
|---|---|
| Dev-Event | 한국 개발자 행사·대회 목록 ([brave-people/Dev-Event](https://github.com/brave-people/Dev-Event) 공개 목록) |
| 위비티 | 공모전 포털의 IT·SW·과학/공학 분야 목록 |
| 콘테스트코리아 | **대외활동**(인턴·서포터즈·동아리·봉사)과 IT·학문·창업 분야 공모전 |
| RSS/Atom | `EVENT_FEEDS` 에 넣은 주소 (선택) |
| 직접 등록 | 화면의 [공고 주소 직접 등록] |

- 설정(`.env`): `EVENT_CRAWL_ENABLED`, `EVENT_CRAWL_INTERVAL_HOURS`, `EVENT_SOURCES`, `EVENT_FEEDS`
- **지키는 규칙**: 각 사이트의 `robots.txt` 가 허용하는 곳만 읽고, 같은 사이트에는 1초 간격으로 요청하며, 식별 가능한 User-Agent(`DureSyncBot`)를 써요. 제목·주최·날짜·태그 같은 사실 정보와 **원문 링크**만 저장하고 본문은 복사하지 않아요. 카드에는 출처를 표시해요.
- **포스터 이미지**: 새로 들어온 이벤트의 페이지에서 대표 이미지(`og:image`) 주소만 찾아 저장하고, 브라우저가 원본 사이트에서 직접 불러와요(서버가 이미지를 복사·저장하지 않아요). 이미지가 없거나 불러오지 못하면 분류별 자동 생성 포스터를 보여줘요. `EVENT_IMAGE_BATCH` 로 한 번에 찾는 개수를 조절하고 0 이면 꺼요.
- 출처 하나가 실패해도 나머지는 계속 돌고, 실패 이유는 화면 상단에 표시돼요. 결과가 비면(사이트 구조 변경) 기존 데이터는 건드리지 않아요.
- 서비스를 **상업적으로 공개하기 전에는** 위비티 등 각 사이트의 이용약관을 확인하거나 제휴·공식 API 를 알아보세요.
- 공고 주소 직접 등록은 서버가 그 주소를 대신 열어 보기 때문에, 내부망 주소(localhost·사설 IP 등)는 막혀 있어요.

### 📞 팀 통화방

채팅 탭 바로 아래 **통화 탭**을 누르면 디스코드처럼 방 목록이 펼쳐집니다. 음성은 팀원 브라우저끼리 직접 연결(WebRTC)돼 지연이 가장 작아요.

- **기본 통화방**은 프로젝트 이름을 그대로 따라가요. 채팅 헤더의 ✏️ 로 프로젝트 이름을 바꾸면(소유자만) 통화방 이름도 함께 바뀝니다.
- **방 만들기**로 프로젝트마다 최대 8개의 방을 더 만들 수 있고, 방마다 최대 6명까지 들어올 수 있어요.
- **다른 장소(다른 네트워크)에서 통화하려면 TURN 중계 서버가 필요합니다.** `.env` 의 `TURN_URLS` 와 `TURN_USERNAME`/`TURN_CREDENTIAL`(Metered 등) 또는 `TURN_SECRET`(직접 운영하는 coturn)을 설정하세요. 설정이 없으면 화면에 안내가 표시되고, 같은 네트워크에서만 확실히 연결돼요.
- 마이크는 `https` 또는 `localhost` 주소에서만 쓸 수 있어요.
- **효과음(디스코드처럼):** 팀원의 **새 채팅**, **통화방 입장(올라가는 소리)·퇴장(내려가는 소리)**, **팀원이 들어오고 나갈 때**, **마이크 끄기/켜기**에 짧은 소리가 나요. 소리 파일 없이 브라우저가 직접 만들어서(Web Audio) PC·모바일·PWA 모두 같고, 통화창·채팅창 위의 🔔 로 끌 수 있어요(이 브라우저에 저장). 내 메시지·AI 답변·처음 불러온 예전 메시지에는 소리가 나지 않고, **방해금지** 상태에서는 채팅 소리가 나지 않아요. (브라우저 정책상 화면을 한 번 누르기 전에는 소리를 낼 수 없어요.)
- **자동으로 나가지던 문제 수정:** ① 채팅·워크스페이스에서 프로젝트가 바뀌면 통화가 끊기던 것을 없앴어요 — 통화는 들어간 프로젝트에 고정되고 프로젝트를 바꿔도 이어져요(특히 **폴더 가져오기** 뒤 워크스페이스가 다른 프로젝트로 다시 열리며 통화가 끊기던 문제). ② 연결이 잠깐 끊겨도 통화를 끝내지 않고 **마이크를 유지한 채 자동으로 다시 연결**해요(최대 8번, 약 26초). ③ 15초마다 ping 을 보내 와이파이 전환·절전 뒤처럼 조용히 죽은 연결을 알아채고 다시 연결해요. 로그인 만료·방 삭제·다른 곳에서 접속한 경우에는 이유를 알려 주고 끝내요. 테스트: `node tests/test_call_client.js`

### 👥 팀원 화면 · 임시 서버 자동 로그인

- 상단 **팀원** 탭(`/app/team`): 프로젝트별로 누가 접속 중인지(온라인·자리비움·방해금지·오프라인)를 보고, 접속 상태별로 걸러 볼 수 있어요. 소유자는 여기서 팀원 초대·역할 변경(팀장/팀원)·내보내기를, 팀원은 탈퇴를 할 수 있어요. 접속 상태는 실시간으로 바뀝니다.
- **임시(로컬) 서버용 자동 로그인:** 서버를 켤 때 `DEV_AUTO_LOGIN_EMAIL=내이메일@gmail.com` 을 주면, 로그인 버튼을 누르는 순간 그 이메일의 *이미 있는* 계정으로 바로 로그인돼요. 내 컴퓨터(127.0.0.1)에서 직접 접속할 때만 동작하고(프록시·외부 접속은 거부), 계정을 새로 만들지 않아요. **배포 서버에서는 비워 두세요.**
  ```bash
  DEV_AUTO_LOGIN_EMAIL=내이메일@gmail.com EVENT_CRAWL_ENABLED=false .venv/bin/uvicorn main:app --app-dir api --host 127.0.0.1 --port 8080
  ```

### ▶ 워크스페이스: 코드 실행 · 파일 탐색기

- **실행 언어:** 파일 확장자로 정해져요 — Python(.py) · JavaScript(.js) · TypeScript(.ts) · Java(.java) · C(.c) · C++(.cpp) · C#(.cs) · Ruby(.rb) · PHP(.php) · Perl(.pl) · Bash(.sh) · Go(.go) · Rust(.rs). **서버에 설치된 도구만** 자동으로 실행 가능 목록에 올라가고(`/health`), 없는 언어는 가짜 결과 없이 "이 서버에는 ○○ 실행 환경이 없어요"라고 알려줘요. `.md`·`.txt` 같은 파일은 실행하지 않아요(예전처럼 몰래 Python 으로 돌려서 오류가 나지 않아요).
- **Java:** 클래스 이름이 `Main` 이 아니어도, `public` 이 없어도, `package` 가 있어도 실행돼요(`main` 이 있는 클래스를 찾아요).
- **배포 서버(Docker) — 핵심 언어만 두고, 나머지는 관리자 페이지에서 관리해요.**
  - **이미지에 들어 있는 것:** Python 3.13 · Node.js 24 LTS(JavaScript/TypeScript) · Java(JDK) · C/C++(gcc) · Bash. **HTML · CSS 는 서버가 아니라 사용자 브라우저에서 미리보기로 동작**해서 설치가 필요 없어요.
  - **사용자에게 열어 둘 언어는 관리자가 정해요.** 처음에는 핵심 언어(Python · JavaScript · TypeScript · Java · C · C++ · C#)만 공개되고, Ruby · PHP · Perl · Bash · Go · Rust 는 서버에 설치돼 있어도 **관리자가 켜기 전에는 목록에서 숨겨져요**(공개하지 않은 언어로 ▶ 실행하면 "언어 지원이 되지 않습니다" 안내창).
  - **관리자 페이지 → 언어 관리** (`/app/admin`): 언어별 공개/비공개 켜기·끄기, 런타임(Node · Java · C#(.NET) · Go · Rust)의 **설치 · 업데이트 · 삭제 · 기본 버전 지정**, 설치 진행 로그, 남은 디스크가 있어요(변경은 최고관리자만). 설치할 수 있는 버전(예: Java 21 LTS · 25 LTS, Node 22 · 24 LTS)은 공식 사이트에서 불러와요. 이미지에 포함된 Python · C · C++ 는 서버를 다시 빌드할 때 갱신돼요.
  - **같은 언어의 여러 버전을 나란히 설치**할 수 있고(`./langs/java/21.0.5`, `./langs/java/17.0.13` …), 버전이 2개 이상이면 워크스페이스 **▶ 실행 옆 선택 박스**에서 사용자가 고르고(고른 버전은 브라우저가 기억), 안 고르면 관리자가 정한 기본 버전으로 실행돼요. 목록 API: `GET /api/languages`.
  - **서버 터미널에서도 똑같이** (재빌드·재시작 없음):
    ```bash
    docker compose -f docker-compose.prod.yml exec app install-lang list               # 설치 현황(버전 포함)
    docker compose -f docker-compose.prod.yml exec app install-lang available java      # 설치할 수 있는 버전
    docker compose -f docker-compose.prod.yml exec app install-lang java 21             # Java 21 설치 (node · go · rust · dotnet 도 같은 방식)
    docker compose -f docker-compose.prod.yml exec app install-lang default java 21.0.5 # 기본 버전
    docker compose -f docker-compose.prod.yml exec app install-lang remove java 17.0.13
    ```
    설치한 언어는 `./langs`(컨테이너 안 `/opt/langs`, 도커 볼륨)에 저장돼서 **컨테이너를 새로 만들어도 남아요.** 서버가 10초 안에 자동으로 알아봐요. 공식 배포처(nodejs.org · adoptium.net · go.dev · static.rust-lang.org · dot.net)에서 HTTPS 로 받고 체크섬을 확인해요. 디스크는 Go 약 250MB · Rust 약 500MB · Node 약 200MB · JDK 약 300MB · .NET 약 1GB 쓰니 여유를 확인하세요(`./langs` 는 깃허브에 올라가지 않아요). 옛 방식(버전 폴더 없이 `./langs/go/bin/go`)으로 설치한 것도 `legacy` 버전으로 인식해요.
  - **Java Spring 은 ▶ 실행으로 돌릴 수 없어요**(웹 서버를 띄우는 프레임워크라 빌드·의존성·포트가 필요). Spring 코드를 실행하면 안내창이 떠요. 일반 Java 문법은 그대로 실행돼요.
  - **내 PC에 설치한 언어로 실행**하는 기능은 아직 없어요(브라우저가 PC 프로그램을 직접 실행할 수 없어서 연결 프로그램이 필요해요 — 필요하면 별도 단계로 추가).
  - 새 언어(예: Kotlin)를 지원 목록에 넣는 건 코드 수정이 필요해요. 실행되는 코드에는 서버의 환경변수(비밀키)를 넘기지 않고, 시간·출력 크기를 제한해요.
  - *개발 컴퓨터에서 이미지를 직접 빌드할 때 `Unable to connect to deb.debian.org` 가 나면* 인터넷이 잠깐 끊긴 것이라 다시 실행하면 돼요(Dockerfile 에 apt 재시도 설정이 들어 있어요).
- **⚠️ 보안:** 이 샌드박스는 서버 안에서 코드를 직접 돌려요(컨테이너/VM 수준의 완전한 격리가 아니에요). 누구나 접속하는 공개 서버에서는 `PUBLIC_MODE=true` 로 실행을 끄거나, Judge0 같은 별도 격리 환경을 쓰는 것을 권장해요.
- **파일 탐색기(VS Code 방식):** 폴더를 누르면 그 폴더가 선택되고, 위의 **새 파일 / 새 폴더** 버튼(또는 폴더에 마우스를 올렸을 때 나오는 버튼)을 누르면 **그 폴더 안에 입력칸**이 바로 생겨요 — 이름만 입력하면 돼요. 빈 곳을 누르면 맨 위(루트)가 선택돼요. 빈 폴더는 보이지 않는 `.gitkeep` 파일로 유지돼요. 폰·태블릿에서는 이름 바꾸기·삭제 버튼이 항상 보여요.
- **이름 규칙:** `.` `..` `...` 처럼 점으로만 된 이름, `\ : * ? " < > |` 문자, 끝의 마침표/공백은 쓸 수 없어요(`a..b.txt`·`.gitignore` 는 가능). 서버가 거부한 파일이 화면에만 남는 일은 없어요.

### 📲 앱으로 설치 (PWA)

- **설치:** 크롬·엣지·삼성 인터넷은 아바타 메뉴 → **앱으로 설치**(또는 주소창의 설치 아이콘). iPhone/iPad 는 버튼을 누르면 *공유 → 홈 화면에 추가* 안내가 나와요. 설치하면 홈 화면/앱 목록에 DureSync 아이콘이 생기고 브라우저 주소창 없이 앱처럼 열려요.
- **아이콘(라이트/다크):** 브랜드 로고(`docs/brand/mark-full.png`)로 만든 아이콘이 `frontend/icons/` 에 있어요 — 라이트(흰 배경) · 다크(`#0B1020`) 두 벌과 안드로이드용 maskable·모노크롬(테마 아이콘)·iOS 180px·탭 아이콘. 화면 모드(앱에서 고른 라이트/다크 또는 기기 설정)를 따라 설치용 아이콘·탭 아이콘·상단 색이 자동으로 바뀌어요. 아이콘을 다시 만들려면 `.venv/bin/pip install pillow` 후 `.venv/bin/python scripts/make_pwa_icons.py`.
  - ⚠️ 홈 화면 아이콘은 **설치하는 순간**의 모드로 정해져요. 설치한 뒤에 모드를 바꿔도 이미 만든 아이콘은 운영체제가 정하므로 자동으로 바뀌지 않아요(다시 설치하면 새 모드 아이콘). iOS 는 웹앱의 다크 전용 아이콘을 따로 지원하지 않아서, 추가하는 순간의 모드 아이콘이 쓰여요.
- **빠르고 안전하게:** 서비스 워커(`/sw.js`)는 화면 파일(CSS·JS·아이콘)만 기기에 보관해서 다시 열 때 빨라요. **로그인·채팅·파일 같은 서버 데이터(`/api`, `/ws`)는 절대 보관하지 않아요.** 연결이 끊긴 채 열면 오프라인 안내 화면이 나오고, 연결이 돌아오면 자동으로 앱으로 돌아가요.
- **새 버전:** 배포로 화면이 바뀌면 "새 버전이 나왔어요" 알림이 떠요. 누르면 새로고침돼서 적용되고(쓰던 화면이 갑자기 바뀌지 않아요), 옛 보관분은 자동으로 지워져요.
- **매니페스트:** `/manifest.webmanifest?theme=light|dark` (서버가 만들어 줘요). 바로가기: 워크스페이스·회의록·캘린더·커뮤니티 (설치한 앱 아이콘을 길게 누르면).
- 설치는 **HTTPS**(또는 localhost)에서만 돼요. 배포 서버는 이미 HTTPS 예요.

### ▶ 실행 · 결과 미리보기 (워크스페이스)

- **실행 버튼은 하나예요(▶ 실행, `Ctrl+Enter`).** 예전의 "배치 실행"은 없어졌고, 실행하면 아래 **실행 콘솔**에 결과가 실시간으로 나와요. 프로그램이 입력(`input()`, `Scanner` 등)을 기다리면 콘솔 아래 **INPUT** 칸에 값을 넣고 Enter. **■ 중지**로 강제 종료. (WebSocket `/ws/terminal`, 로그인한 사용자만)
- **파일 이름 ↔ 코드 이름 연동**
  - 실행할 때 **내가 연 파일의 이름 그대로** 실행해요(오류 메시지·트레이스백에 `calc.py` 처럼 내 파일 이름이 나와요).
  - **자바**는 public 클래스 이름과 파일 이름이 같아야 해요(자바 규칙). 다르면 실행하지 않고 *"파일 이름을 ○○.java 로 바꾸고 실행 / 클래스 이름을 ○○ 로 바꾸고 실행"* 버튼을 보여 줘요. 편집 중에도 상태바에 **⚠ 파일명 ≠ 클래스명**이 떠서 누르면 맞춰 줘요.
  - 탐색기에서 **자바 파일 이름을 바꾸면 public 클래스 이름도 같이 바뀌어요**(문자열·주석 안은 건드리지 않아요). **새 .java 파일**은 파일 이름과 같은 클래스가 들어 있는 상태로 만들어져요(새 .html 도 기본 뼈대).
  - 파이썬의 `random.py` 처럼 표준 모듈과 같은 이름이거나 이상한 이름은 안전한 기본 이름(`main.py`)으로 실행해요.
- **새 파일 기본 코드:** 파일을 만들면 언어에 맞는 "Hello, World!" 기본 코드가 들어가요 — Java(파일 이름과 같은 `public class`) · Python · JavaScript · TypeScript · C · C++ · C# · Go · Rust · Ruby · PHP · Perl · Bash · HTML · CSS · Markdown.
- **줄임말 자동완성(스니펫):** IntelliJ·VS Code 처럼 줄임말을 치면 코드가 펼쳐져요 (목록 맨 위에 뜨고 Enter 또는 Tab, 이어서 Tab 으로 다음 칸 이동). 예) 자바 `sout` → `System.out.println();` · `psvm`/`main` → main 메서드 · `fori` · `foreach` · `scan` · `try`, 파이썬 `fori` · `def` · `inpi`(정수 입력) · `with`, JS/TS `log` · `afn` · `fetch` · `qs`, C `printf` · `scanf`, C++ `cout` · `cin` · `vec`, C# `cw`, Go `pl` · `iferr`, Rust `pl` · `match`, HTML `html5` · `div` · `btn`, CSS `flex` · `grid` · `media` … (자바 `class` 는 현재 파일 이름으로 클래스를 만들어 줘요). 목록은 `frontend/js/pages/workspace.js` 의 `WS_SNIPPETS` 에서 고칠 수 있어요.
- **폰·태블릿 입력줄:** 터치 기기에서 코드 입력칸을 누르면 키보드 위에 `Tab` · `{ }` · `( )` · `[ ]` · `;` · `"` · `=` · 방향키 · 되돌리기 같은 키가 줄지어 떠요(키보드가 올라온 높이를 따라가고, 설치한 앱(PWA)에서도 같아요). 선택한 글자가 있으면 괄호·따옴표로 감싸요.
- **미리보기 창(에디터 옆의 작은 브라우저):** `.html` 파일(또는 그 HTML 이 쓰는 `.css` / 브라우저용 `.js`)에서 **▶ 실행**을 누르거나 위쪽 **미리보기** 버튼을 누르면 열려요. 넓은 화면(PC·큰 태블릿)에서는 **에디터 오른쪽에 나란히** 붙고 가운데 줄을 끌어서 너비를 바꿀 수 있어요(두 번 누르면 기본 너비), 폰·좁은 화면(900px 이하)에서는 에디터 위를 **덮는 전체 화면**으로 열려서 ✕ 로 돌아와요. 위에는 **주소창 · 뒤로/앞으로 · 새로고침 · 새 탭에서 열기**가 있어요. 주소창에 파일 경로(`about.html`, `about`)를 쓰고 Enter 를 누르면 이동하고, 미리보기 안의 링크를 누르면 프로젝트의 그 파일로 이동해요(바깥 사이트 링크는 새 탭). 같은 폴더의 CSS·JS 를 합쳐서 그리고, **꽉 채움 · 모바일(390×844) · 태블릿(820×1180) · PC(1280×800)** 로 바꿔 볼 수 있고 가로/세로 돌리기도 돼요. 기기를 바꾸면 그 크기로 화면을 다시 불러와서 CSS 미디어쿼리와 `innerWidth` 가 실제 기기처럼 반응해요. 코드를 고치면(팀원이 고쳐도) 잠깐 뒤 자동으로 다시 그리고 **스크롤 위치는 그대로** 둬요. 미리보기 안의 `console.log` / 오류는 실행 콘솔에도 나와요. 미리보기는 앱과 분리된 창(sandbox)이라 로그인 정보·저장소에 접근할 수 없고, 서버에서 실행하지 않고 내 브라우저에서만 그려요(그래서 Flask·Node 같은 서버 앱은 미리볼 수 없어요).
- **실행 이력:** 실행할 때마다(성공·실패·컴파일 에러·중지) 로그인 계정의 **실행 이력** 탭에 남고, 누르면 그때 코드와 출력을 되돌려요.
- 실행할 수 없는 파일(`.md` 등)이나 서버에 없는 언어는 이유를 콘솔에 알려 줘요. 로그인하지 않으면 실행할 수 없어요.
- **안전장치:** 로그인한 사용자만(서버가 토큰 확인), `PUBLIC_MODE` 에서는 꺼짐, 서버 환경변수(비밀키)를 넘기지 않음, 한 번에 `TERMINAL_MAX_SECONDS`(기본 300초)·출력 1MB 제한.
- 참고: 옛 일괄 실행 API `POST /api/run` 은 화면에서 쓰지 않지만 외부 연동용으로 남아 있어요(아래 보안 참고).

### 🪟 자바 GUI(Swing/AWT) 창 — 사이트 안에서 바로 띄우기

`javax.swing`·`java.awt` 를 쓰는 자바 파일에서 **▶ 실행**을 누르면 서버에는 화면이 없어도 **사이트 안의 "GUI 창" 패널**에 창이 떠요 (PC · 모바일 · PWA 모두). 코드는 자바 **그대로**예요 — 변환하지 않아요.
- **서버**는 진짜 `javac` 로 프로젝트의 `.java` 파일들을 컴파일해서 `.jar` 로 묶어 주기만 해요(서버에서 실행하지 않아요 → 서버 메모리를 거의 안 써요). `POST /api/gui/java/build` (로그인 필요).
- **브라우저**가 [CheerpJ](https://cheerpj.com)(브라우저 안의 자바 실행 환경)로 그 jar 를 실행해서 창을 그려요. `System.out` 출력은 실행 콘솔에 나와요. ▶ 로 다시 실행, ✕ 또는 ■ 로 닫기.
- 자바 코드가 **내 PC 에서 실행**으로 선택돼 있으면 예전처럼 내 컴퓨터의 창으로 떠요.
- **한계:** 진짜 JDK 가 아니라 브라우저 안의 자바라서 JavaFX·일부 라이브러리는 안 돼요(Swing/AWT 중심). 입력(`Scanner`)은 지원하지 않아요. 처음 한 번은 자바 실행 환경을 내려받느라 20~40초 걸려요(이후엔 브라우저에 저장). CheerpJ 는 **개인·비영리 용도 무료**예요(상업 서비스가 되면 라이선스 필요).
- **보안:** 컴파일은 `-proc:none`(어노테이션 프로세서 끔)·서버 환경변수 미전달·제한 시간. 컴파일된 `.class` 에 **이름으로 클래스 불러오기·리플렉션·JS 연결(`netscape.javascript`)·native 메서드**가 있으면 거절해요. 창은 로그인 정보를 모르는 별도 페이지(`frontend/gui/frame.html`)를 iframe 으로 열어 그려요. 더 단단히 하려면 `GUI_FRAME_ORIGIN`(예: `https://gui.duresync.cloud`)으로 **다른 주소**에서 열게 할 수 있어요 — 설정 방법은 `Caddyfile` 맨 아래 주석. 개발할 때(`localhost` ↔ `127.0.0.1`)는 자동으로 분리돼요.
- 테스트: `.venv/bin/python tests/test_gui_build.py` · `node tests/test_gui_client.js`

### 🖥️ 내 PC 에서 실행 (러너)

서버에 없는 언어(Ruby·Kotlin 등)나 서버와 다른 버전은 **내 컴퓨터에 설치한 것**으로 실행할 수 있어요. 브라우저는 내 컴퓨터의 프로그램을 직접 켤 수 없어서, 작은 연결 프로그램(**러너**, Python 파일 하나)을 내 컴퓨터에 설치해 둡니다. 설치는 **한 줄 복사 → 터미널에 붙여넣기**가 전부예요.

1. 워크스페이스 위쪽 **🖥️ 내 PC** 버튼을 눌러요. 맥/윈도우/리눅스 탭(자동 선택)에 **터미널 여는 법**(맥: `⌘+Space` → "터미널" / 윈도우: 윈도우 키 → "PowerShell")과 **한 줄 설치 명령**이 나와요.
2. 그 한 줄을 복사해서 터미널에 붙여넣고 Enter. **어느 폴더에서 실행해도 돼요.** (러너 내려받기 · `~/.duresync-runner` 설치 · 컴퓨터를 켤 때마다 자동 시작 등록을 한꺼번에 해요)
   - 맥·리눅스: `curl -fsSL https://사이트/runner/install.sh | DURESYNC_TOKEN=코드 sh`
   - 윈도우(PowerShell): `$env:DURESYNC_TOKEN='코드'; irm https://사이트/runner/install.ps1 | iex`
   - 연결 코드는 **사이트가 정해서 명령에 넣어 줘요**(직접 입력 불필요).
3. 끝. 창이 2.5초마다 확인해서 **알아서 "✓ 연결됨"**으로 바뀌고, 연결되면 설치 안내는 숨고 내 컴퓨터에서 찾은 언어 목록·스위치만 보여요. 안 될 때를 위해 창 안에 **"자주 나오는 에러와 해결법"**(파이썬 없음 · 내려받기 실패 · 연결 안 됨 · 코드 불일치)이 있어요.
   - 파이썬이 없으면 스크립트가 **무엇을 설치해야 하는지** 알려 주고 끝나요(윈도우는 `winget install Python.Python.3.12` 도 안내).
   - 새로 설치한 언어는 ▶ 실행할 때 러너가 **알아서 다시 찾아요**(재시작·'다시 검색' 불필요). 고른 버전이 지워졌으면 몰래 다른 버전으로 돌리지 않고 이유를 알려 줘요.
   - 같은 와이파이를 써도 상관없어요. 러너는 **각자 자기 컴퓨터 안(127.0.0.1)**에서만 열려서, 컴퓨터마다 한 번씩 설치하면 돼요.
   - 끄기·지우기: `python3 ~/.duresync-runner/duresync_runner.py --uninstall-autostart` (윈도우: `py "$env:USERPROFILE\.duresync-runner\duresync_runner.py" --uninstall-autostart`). 수동 실행/옵션: `duresync_runner.py` `--install-autostart` `--token` `--port` `--allow-origin` `--max-seconds` `--show-token` `--reset-token` `--dry-run` `--no-start`.
- **창(GUI)이 뜨는 프로그램**(Java Swing·AWT·JavaFX, Python tkinter·pygame, C/C++ SDL·GTK …)은 화면이 없는 서버에서는 실행할 수 없어요(`HeadlessException` 같은 오류). 서버에서 이런 오류가 나면 콘솔에 이유와 **[🖥️ 내 PC 에서 실행]**(또는 연결 방법) 버튼이 나와요. 내 PC 로 실행하면 창이 **내 화면**에 떠요. 러너의 한 번 실행 제한 시간은 기본 30분(`--max-seconds`)이에요.
4. 같은 언어가 서버와 내 PC 에 모두 있거나 버전이 여러 개면 ▶ 실행 옆 **선택 박스**에서 `서버 · Java 25 / 내 PC · Java 17` 처럼 고르면 돼요(고른 것은 기억). 서버와 내 PC 어디에도 없으면 **"언어 지원이 되지 않습니다"** 안내창이 떠요.

- **PC 브라우저 전용** (크롬·엣지·파이어폭스). **폰·태블릿·설치형 앱(PWA)** 에서는 서버가 지원하는 언어만 실행돼요(그 외는 "언어 지원이 되지 않습니다"). 사파리는 https 사이트에서 내 컴퓨터(127.0.0.1)로의 연결을 막아서 쓸 수 없어요.
- 내 PC 실행은 **사이트 로그인 없이** 되고, **실행 이력에는 남지 않아요**. 코드는 내 컴퓨터에서 내 권한으로 실행되니 믿을 수 있는 코드만 실행하세요(서버처럼 격리되지 않아요).
- **실행 전 확인:** 내 PC 로 처음 실행할 때 "서버처럼 격리되지 않아요" 안내가 뜨고(다시 보지 않기 가능), **팀원이 고친 코드**(마지막 저장자가 내가 아니거나 실시간 편집으로 바뀐 코드)는 실행할 때마다 *"팀원이 고친 코드예요 — 확인했어요, 실행"* 동의를 받아요(같은 코드를 이미 확인했으면 다시 묻지 않아요). 서버에도 있는 언어는 기본이 **서버(격리)** 예요.
- **내 PC 실행 사용 스위치:** 🖥️ 내 PC 창 맨 위 스위치를 끄면 러너가 켜져 있어도 항상 서버로만 실행돼요(이 브라우저에만 저장).
- **보안:** 러너는 내 컴퓨터(127.0.0.1)에서만 열리고, 사이트에서 내려받은 러너는 **그 사이트 주소(`PUBLIC_BASE_URL`/접속 주소)의 요청만** 받아요(Origin·Host 확인). 거기에 **연결 코드**(내 컴퓨터 `~/.duresync-runner/token`)를 아는 브라우저만 연결돼요. 다른 사이트의 스크립트나 같은 와이파이의 다른 컴퓨터는 쓸 수 없어요. 옵션: `--port` · `--allow-origin 주소` · `--max-seconds` · `--show-token` · `--reset-token`.
- 구성: `runner/duresync_runner.py`(러너 원본, 표준 라이브러리만 사용) · `GET /runner/duresync_runner.py`(내려받기, 사이트 주소를 넣어서 줘요) · `GET /runner/install.sh` · `GET /runner/install.ps1`(한 줄 설치 스크립트) · `tests/test_runner_install.py` · `GET /api/runner`(최신 버전 확인) · `frontend/js/pages/workspace-runner.js`(화면) · `tests/test_runner.py`.

- 개발: `chat_messages.private_to`(그 사용자 id) 컬럼으로 구분해요(기존 DB 는 서버가 켜질 때 자동으로 컬럼을 추가). 테스트: `tests/test_ai_private_chat.py`.

### ⚡ 실시간 공동 편집 (글자 단위)

- **같은 파일을 연 팀원끼리 한 글자가 쳐지는 순간 서로 화면에 나타나요** — 저장이나 Enter 를 기다리지 않아요. 팀원이 새로 친 글자는 그 사람 색으로 잠깐(약 2초) 표시되고, 파일 목록·탭의 작은 프로필과 에디터 안 커서·이름표(기존 기능)가 어디서 작업 중인지 계속 보여 줘요. 상태바에는 `⚡ 실시간 · 자동 저장`(동기화 중엔 `⟳ 동기화 중…`)이 떠요.
- **동시에 같은 곳을 고쳐도 꼬이지 않아요.** 서버(`api/services/livedoc.py`)가 파일마다 '방'을 하나 두고 편집의 순서를 정하며, 화면(`frontend/js/pages/workspace-live.js`)과 서버가 같은 변환 규칙(OT, `api/services/ot.py`)을 써서 모두 같은 글로 끝나요. 서버가 점검값(adler32)을 가끔 보내서 어긋나면 스스로 다시 맞춰요.
- **저장은 서버가 알아서 해요**(마지막 입력 0.8초 뒤, 마지막 사람이 나가면 바로). 실시간으로 받는 파일은 화면이 저장 요청(PUT)을 따로 보내지 않아서 "누가 먼저 수정했어요" 충돌 안내가 생기지 않아요. `Ctrl+S` 는 "지금 저장"만 요청해요.
- **Ctrl+Z / Ctrl+Y 는 '내가 한 편집만'** 되돌려요. 팀원이 위쪽에 줄을 넣어도 엉뚱한 곳이 지워지지 않아요(되돌리기 기록의 위치를 남의 편집에 맞춰 같이 옮겨 둬요).
- **한글 같은 조합 입력 중에는** 팀원 편집 적용을 잠깐 미뤄서 조합 중인 글자가 깨지지 않아요.
- **끊겨도 안전해요.** 실시간 연결이 끊기면 예전 방식(자동 저장 + 충돌 확인)으로 저절로 돌아가고, 아직 못 보낸 입력은 일반 저장으로 보관돼요. 다시 연결되면 자동으로 다시 붙어요. 서버를 껐다 켜도 마찬가지예요. (방은 메모리에만 있어서 서버가 꺼지면 마지막 0.8초 입력은 저장되지 않을 수 있어요.)
- 줄바꿈은 `LF` 로 통일해서 저장해요(예전에 `CRLF` 로 저장된 파일도 처음 실시간 편집할 때 `LF` 가 돼요). 파일 하나 최대 30만 자.
- 다른 경로(예: 오래된 화면에서 일반 저장·이름 변경·삭제)로 파일이 바뀌면 그 방이 닫히고 화면이 새 내용을 다시 받아요.
- 테스트: `tests/test_ot.py`(변환 규칙 무작위 3만 번 + 파이썬/자바스크립트 결과 일치), `tests/test_livedoc_ws.py`(접속자 여러 명·동시 입력·저장·권한·끊김).

### 🚀 속도 (모바일 · PC · PWA)

- **코드 편집기(Monaco, 약 0.7MB)는 워크스페이스를 열 때 불러와요.** 홈 화면은 그만큼 덜 받아요(느린 4G·CPU 4배 느림 기준 처음 그려지기까지 2.3초 → 1.2초, 전체 로딩 7.7초 → 3.2초, 받는 양 981KB → 273KB). 빠른 PC 에서는 홈이 다 그려진 뒤 한가할 때 미리 받아 둬서 처음 열 때도 바로 떠요(데이터 절약 모드·느린 망·폰에서는 미리 받지 않아요).

- 실시간 알림은 받을 화면 모두에게 **동시에** 보내요(느린 화면 하나가 나머지를 기다리게 하지 않고, 3초 안에 못 받으면 건너뛰어요). 팀원 커서 신호는 60ms 마다.

# 올인원 백엔드: 자체 DB, JWT 인증, 코드 실행 샌드박스 & Cloudflare Tunnel

개인 PC 환경에서 **자체 데이터베이스(SQLAlchemy + SQLite/PostgreSQL)**, **JWT 사용자 인증/인가**, **Python & Java 격리 샌드박스**, **실시간 웹소켓 Hub**를 직접 구축하고, **Cloudflare Tunnel**을 통해 외부 Vercel 프론트엔드(Next.js)와 완벽하게 통신할 수 있는 올인원 백엔드 시스템입니다.

---

## 1. 시스템 아키텍처

```
[Vercel Frontend (Next.js)]
         │
         ▼ (HTTPS / WSS 보안 터널)
[Cloudflare Tunnel (*.trycloudflare.com)]
         │
         ▼ (Localhost:8000 포워딩)
[FastAPI 백엔드 서버 (:8000)]
   ├── [Auth] JWT 토큰 발급/검증 (bcrypt 암호화)
   ├── [DB] SQLAlchemy 2.0 Async (c:\backend\data\app.db)
   │     ├── users (회원 계정)
   │     └── submissions (코드 실행 이력)
   ├── [Realtime] WebSocket Hub (/ws/events)
   └── [Sandbox] 격리 샌드박스 엔진
         ├── Python 3.11 런타임 (프로세스 격리)
         └── OpenJDK 17 Hotspot (512MB 힙 제한, javac 컴파일)
```

## 2. API 엔드포인트 명세

### 1) 인증 및 계정 관리 (`/api/auth`)
* `POST /api/auth/signup`: 신규 회원가입 (이메일, 비밀번호, 닉네임) -> JWT 토큰 즉시 반환
* `POST /api/auth/login`: 로그인 -> JWT 토큰 반환
* `GET /api/auth/me`: 현재 로그인한 사용자 프로필 조회 (`Authorization: Bearer <token>` 필요)

### 2) 코드 실행 및 히스토리 (`/api`)
* `POST /api/run`: 코드 실행 요청
  * 토큰이 포함된 경우: 실행 결과가 DB `submissions` 테이블에 자동 저장되고 `submission_id` 반환
  * 비로그인(게스트)인 경우: DB 저장 없이 즉시 실행 결과 반환
* `GET /api/submissions`: 내 실행 히스토리 목록 페이징 조회 (`skip`, `limit`)
* `GET /api/submissions/{id}`: 특정 실행 결과 상세 조회

### 3) 실시간 웹소켓 & 헬스체크
* `WS /ws/events`: 코드 실행 이벤트 실시간 수신 웹소켓
* `GET /health`: 서버, 자체 DB, 샌드박스 엔진 상태 점검
* `GET /docs`: 대화형 Swagger API 문서

## 3. 프론트엔드(Vercel Next.js) 연동 가이드

### 1) 환경 변수 설정 (`.env.production` 또는 Vercel 설정)
```env
NEXT_PUBLIC_API_URL=https://allows-newest-observe-mails.trycloudflare.com
```

### 2) Next.js 클라이언트 API 연동 코드 예시

```typescript
// lib/api.ts
const API_BASE = process.env.NEXT_PUBLIC_API_URL;

// 1. 회원가입
export async function signup(email: string, password: string, username: string) {
  const res = await fetch(`${API_BASE}/api/auth/signup`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ email, password, username })
  });
  return await res.json(); // { access_token, user }
}

// 2. 로그인
export async function login(email: string, password: string) {
  const res = await fetch(`${API_BASE}/api/auth/login`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ email, password })
  });
  return await res.json(); // { access_token, user }
}

// 3. 코드 실행 요청 (인증 토큰 동봉 시 DB에 자동 저장)
export async function runCode(code: string, language: string, token?: string) {
  const headers: Record<string, string> = { 'Content-Type': 'application/json' };
  if (token) headers['Authorization'] = `Bearer ${token}`;

  const res = await fetch(`${API_BASE}/api/run`, {
    method: 'POST',
    headers,
    body: JSON.stringify({
      source_code: code,
      language: language,
      stdin: '',
      cpu_time_limit: 5.0
    })
  });
  return await res.json(); // { status, stdout, stderr, execution_time, submission_id }
}

// 4. 내 실행 히스토리 조회
export async function getSubmissions(token: string) {
  const res = await fetch(`${API_BASE}/api/submissions`, {
    headers: { 'Authorization': `Bearer ${token}` }
  });
  return await res.json(); // { total, items: [...] }
}
```

## 프로젝트 단위 협업 기능

- **프로젝트**: 만들기 / 선택 / 삭제(워크스페이스 ⚙ 프로젝트 관리에서 체크 후 휴지통). 회의록·캘린더·채팅·워크스페이스가 모두 프로젝트 단위로 나뉩니다.
- **팀원 초대**: 프로젝트 소유자가 이메일로 초대 (상대가 한 번 로그인한 계정). 초대받은 사람만 그 프로젝트의 채팅·캘린더·파일에 접근합니다.
- **팀 채팅** (`/api/projects/{id}/messages`): 대화에서 "제가 금요일까지 할게요"처럼 담당과 기한이 나오면 AI가 일정 카드를 띄우고, 추가하면 프로젝트 캘린더에 들어갑니다.
- **워크스페이스 파일** (`/api/projects/{id}/files`): 프로젝트별 파일 저장, 자동 저장, 팀원 변경 감지, 동시 수정 충돌 안내.
- **회의록** (`/api/meetings`): 저장·수정·삭제. 수정하면 이전 내용에서 만든 AI 일정을 지우고 다시 분석하며, 삭제하면 그 회의록의 AI 일정도 함께 삭제됩니다.
- **화면 크기 자동 조절**: 창 너비(1440px 기준)에 맞춰 UI 전체를 자동 확대하고, 설정에서 직접 고를 수도 있습니다.
- **AI 분석 엔진**: Gemini(`GEMINI_API_KEY`, 한도(429) 시 `GEMINI_FALLBACK_MODELS`로 자동 전환) → Claude(`ANTHROPIC_API_KEY`) → 규칙 기반(키 불필요).

> API 키와 OAuth 시크릿은 반드시 `.env`(git 제외)에만 넣으세요. `.env.example`에는 빈 칸만 있습니다.

- **"한 사람만 안 돼요 / 등록한 사람만 돼요"는 대부분 앱이 '개발·테스트 중' 상태라서예요.** 코드가 아니라 개발자 콘솔 설정이에요:
  - **네이버:** developers.naver.com → 내 애플리케이션 → 해당 앱 → **멤버 관리**에 로그인할 사람의 네이버 ID 를 추가하거나(최대 인원 제한 있음), **API 설정에서 검수(서비스 승인)를 요청**해 일반 사용자도 쓰게 하세요.
  - **구글:** console.cloud.google.com → API 및 서비스 → **OAuth 동의 화면** → 게시 상태가 **'테스트'** 이면 등록한 **테스트 사용자**만 로그인돼요. **'앱 게시(프로덕션으로 푸시)'** 를 누르면 누구나 로그인할 수 있어요(이메일·프로필만 쓰므로 별도 심사 없이 바로 가능).
  - 허용된 리디렉션 주소가 `https://(도메인)/api/auth/google/callback`, `https://(도메인)/api/auth/naver/callback` 와 정확히 같은지도 확인하세요.
- **`token_exchange_failed` / `naver_profile_failed` 가 PC 에서만 나오던 원인(해결됨):** 소셜 로그인 코드는 **한 번만** 쓸 수 있는데, PC 브라우저(서비스 워커의 '화면 이동 미리 요청'이 켜진 상태)가 로그인 마무리 주소를 **두 번** 요청해서 두 번째가 거부됐어요. 그래서 ① 서비스 워커의 미리 요청을 껐고(`frontend/sw.js`) ② 서버는 같은 코드가 두 번 와도 구글·네이버를 **한 번만** 호출하고 같은 결과를 돌려줘요(`api/routers/auth.py`). 배포 전 PC 에서 급하게 로그인하려면 브라우저 주소창에 `chrome://serviceworker-internals` → `duresync.cloud` 의 **Unregister**(또는 사이트 데이터 삭제) 후 다시 로그인하세요.
- PC 에서만 안 되고 폰에서는 되는 경우: PC 브라우저가 **다른 네이버/구글 계정**으로 이미 로그인돼 있을 수 있어요. 시크릿 창에서 시도해 보세요.
