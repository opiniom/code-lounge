WebSocket 실시간 푸시 엔진 & Live Presence 동기화

주기적 폴링의 한계를 넘어선 이벤트 기반 양방향 실시간 동기화 아키텍처

⚡ /ws/live 양방향 브로드캐스트 엔진

  • SQLAlchemy after_commit 이벤트 훅: 채팅, 일정, 회의록, 팀 변경이 DB에 커밋되는 순간 연결된 소켓으로 즉각 푸시
  • 폴링 부하 90% 절감: 웹소켓 연결 중에는 헬스 폴링 주기를 대폭 늦추며, 끊김 시 자동으로 폴링 폴백(Fallback) 안전망 가동
  • 프로젝트 단위 채널 격리: 소속 팀원에게만 실시간 알림 및 채팅 브로드캐스트

🟢 Live Presence & 협업 인터랙션

  • 실시간 접속 상태 감지: 소켓 연결 즉시 온라인/오프라인 상태가 팀원 아바타와 헤더에 녹색 도트로 전파

  • 스마트 스크롤 & 플로팅 점프: 대화창 자동 스크롤 및 과거 대화 열람 중 새 메시지 도착 시 점프 버튼 표출

Core Feature 2

채팅 내장형 AI 비서: 슬래시 명령어 자동화

회의록 작성과 일정 등록을 대화창 안에서 원클릭으로 해결

/요약 회의록 자동 구조화

채팅창에 /요약을 입력하면 최근 대화 맥락을 즉시 분석하여 주요 안건, 결정 사항, 액션 아이템으로 깔끔하게 정돈해 공유 노트에 보관합니다.

📋 주요 안건: 백엔드 WebSocket 프로토콜 확정
💡 결정 사항: /ws/live 엔드포인트 채택
📌 액션 아이템: 민수 (배포 워크플로우 점검)
/캘린더 자연어 문맥 일정 등록

/캘린더 내일 3시 팀 미팅처럼 자연어 명령을 입력하면, AI가 날짜/시간/제목을 자동 파싱해 공유 캘린더에 즉시 등록합니다.

입력: "/캘린더 내일 15:00 스프린트 회의"
결과: [캘린더 등록 완료] 2026-10-17 15:00 - 스프린트 회의
→ WebSocket으로 팀원 화면 즉시 동기화
💡 안전한 폴백 아키텍처: 외부 LLM API 지연/장애 시에도 자체 룰 기반 자연어 파서가 무중단으로 동작하여 서비스 연속성을 보장합니다.
[NEW] Team Collaboration

실시간 팀 관리 허브(/app/team) & 게스트 온보딩

목업 데이터를 전면 탈피한 100% 실데이터 연동 및 매끄러운 사용자 온보딩 경험

👥 전용 팀 관리 뷰 (/app/team)

  • 실시간 팀원 상태 카드: 온라인/오프라인 여부 실시간 표출 및 프로젝트별 탭 분리
  • 세분화된 RBAC 권한: 팀장(Owner)은 멤버 추방 및 역할 부여, 멤버(Member)는 안전한 자진 탈퇴 지원
  • 인페이지 컨펌 다이얼로그: 브라우저 네이티브 팝업 차단 문제를 예방하는 현대적 인페이지 확인 모달
  • 72시간 만료 초대 토큰: 원클릭으로 안전한 팀 초대 링크 생성 및 즉시 가입

🪐 7-노드 Home Orbit & 게스트 모드

  • 홈 화면 7-노드 오빗(Orbit): 더미 아바타 대신 실제 팀원 6명 + 중앙 AI 비서가 원형으로 배치되어 실시간 상태 표현
  • 게스트 홈(Guest Home) 우선 렌더링: 첫 접속 시 로그인 강제 없이 서비스 탐색 가능, 로그인 시 본인 워크스페이스로 매끄럽게 전환
  • 더미 데이터 전면 제거: 가짜 프로젝트/차트/피드백 제거 후 실제 DB 기반 카운트 연동
인증 플로우: Guest Home 방문 ➔ 서비스 둘러보기 ➔ 상단 "로그인" 클릭 ➔ 본인 대시보드 자동 진입 ➔ 팀 초대 링크 클릭 시 원터치 자동 가입

CHALLENGE 01

무설치 C# 컴파일러 탐색

.NET SDK가 없는 클라이언트 PC에서도 C# 코드를 즉시 컴파일해야 하는 요구사항 발생.

해결: Windows 내장 Framework 디렉터리를 재귀 탐색하여 최적의 csc.exe를 동적 감지하는 알고리즘 구현 성공.
CHALLENGE 02

CP949 인코딩 충돌 보정

Windows 터미널의 기본 CP949 인코딩으로 인해 한글 컴파일 에러 메시지가 깨지는 현상.

해결: 표준 입출력 스트림을 캡처하여 UTF-8 우선 디코딩 및 CP949 폴백 처리하는 하이브리드 비동기 디코더 개발.
CHALLENGE 03

웹소켓 유실 대비 하이브리드 싱크

네트워크 순단 시 실시간 이벤트가 유실되어 클라이언트 데이터 불일치가 발생할 위험.

해결: 소켓 연결 시 폴링을 지연시키고 끊김 감지 시 즉시 백그라운드 폴링으로 전환되는 자가 치유(Self-healing) 구조 완성.
