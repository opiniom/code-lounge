복잡한 로컬 개발 도구 설치 없이 브라우저에서 바로 코드를 작성하고 결과를 확인

5개 대표 프로그래밍 언어 지원

Python, Java, C#, C++, C를 지원하며 각 언어별 전용 컴파일 파이프라인 및 인터프리터 런처가 비동기로 가동됩니다.

Technical Depth

실제 개발 과정에서 극복한 핵심 기술 과제

단순 구현을 넘어 운영 안정성과 사용자 경험을 위해 디테일하게 해결한 이슈들

01

Windows C# 네이티브 컴파일

[문제] dotnet SDK 미설치 환경 컴파일 실패

클라이언트나 서버에 무거운 .NET SDK가 없을 때 C# 코드 실행이 불가능한 한계가 존재했습니다.

[해결] Windows 내부 기본 내장된 C:\Windows\Microsoft.NET\Framework64\...\csc.exe를 자동 재귀 탐색하여 독립 컴파일 실행 성공!
02

Windows 콘솔 CP949 인코딩 충돌

[문제] UnicodeEncodeError 크래시 발생

터미널 실행 및 비동기 프로세스 스트림 처리 시 한국어와 이모지가 Windows 기본 코드페이지(CP949)와 충돌하여 파이썬 프로세스가 강제 종료되는 문제.

[해결] sys.stdout.reconfigure(encoding='utf-8') 및 비동기 바이트 디코더의 replace 에러 핸들러 파이프라인 구축.
03

워크스페이스 빈 화면 구분선 아티팩트

[문제] 파일 없을 때 떠다니는 분할선 노출

워크스페이스에 열린 파일이 없을 때도 CSS z-index와 flex 레이아웃으로 인해 리사이저 막대와 경계선이 화면 중앙에 흉하게 남아있던 UX 결함.

[해결] .ws-shell.is-empty 전용 상태 셀렉터 정의 및 리사이저 바 동적 은폐 + Empty 안내 뷰 최상단 레이어 승격.

Q1. 기존 협업 툴(노션, 슬랙, 디스코드)과 비교했을 때 Code Lounge만의 차별점은?
A. 기존 도구들은 범용 메신저이거나 단순 문서 도구라 코드를 직접 실행할 수 없고 일정이 파편화됩니다. Code Lounge는 "개발팀"에 특화되어 채팅 중 회의록/일정을 AI가 즉각 캘린더에 연동하고, 5개 언어 코드를 브라우저에서 바로 돌려볼 수 있는 컨텍스트 완결형 라운지입니다.
Q2. 코드 실행 샌드박스의 보안과 악의적 코드 대응책은 어떻게 마련되었나요?
A. 현재 비동기 서브프로세스 레벨에서 15초 타임아웃 킬러를 통해 CPU 점유/무한 루프를 원천 차단하며, 메모리와 프로세스 트리를 강제 회수합니다. 향후 프로덕션 단계에서는 Docker 컨테이너 및 리소스 제한(Cgroup)을 결합하여 완벽한 호스트 격리를 제공하도록 설계되었습니다.
Q3. Windows 환경에서 C# 컴파일러(csc.exe)를 연동한 특별한 이유는 무엇인가요?
A. 사용자 및 개발 환경의 설치 허들을 제거하기 위함입니다. 수 기가바이트의 .NET SDK를 설치하지 않아도 Windows 운영체제가 기본 탑재하고 있는 csc.exe를 재귀 검색하여 즉시 실행 가능하도록 구현함으로써 높은 접근성을 달성했습니다.
