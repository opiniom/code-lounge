# 제품개발 학기 프로젝트

**sync/** — 팀 프로젝트를 위한 AI 워크스페이스 UI/UX 프로토타입

코드 워크스페이스, 인스타그램 스타일 채팅, AI 회의록 자동 정리, 일정 자동 감지 캘린더,
공모전·해커톤 크롤링 이벤트, 커뮤니티, 관리자 페이지까지 하나로 묶은
팀 협업 플랫폼의 디자인/프론트엔드 프로토타입입니다.

## 실행 방법

별도 빌드 과정 없이 `index.html`을 브라우저에서 바로 열면 됩니다.

```bash
open index.html
```

## 주요 기능

- **홈** — 제미나이 스타일 첫 화면(신규 회원용) + 위젯 기반 대시보드
- **워크스페이스** — VSCode 스타일 코드 에디터 + 파일 트리
- **전역 채팅** — 어느 화면에서든 열 수 있는 인스타그램 스타일 채팅, `/회의` 명령으로 회의 메모 태깅
- **회의록** — 노션 스타일 자유 작성 → AI가 결정사항·액션아이템으로 자동 정리
- **캘린더** — 회의록/채팅에서 감지한 일정과 개인 일정을 함께 표시
- **이벤트** — 공모전·해커톤 정보 수집 UI
- **커뮤니티** — 팀 간 소식 공유 게시판
- **마이페이지 / 관리자 페이지** — 개인 업무 통계, 팀 업무 분담 AI 분석, 리더 피드백

## 백엔드 연동 기능

- **실제 회원가입 / 로그인 & JWT 세션 유지**: `POST /api/auth/login`, `POST /api/auth/signup`
- **코드 샌드박스 실행 & 터미널**: Python 3 및 Java 17 실시간 컴파일/실행 (`POST /api/run`), 단축키 `Ctrl+Enter` 지원
- **실행 이력(Submissions) 영속화**: 로그인 후 코드 실행 시 SQLite DB에 자동 저장 및 이전 코드/결과 복원 (`GET /api/submissions`)
- **실시간 웹소켓 이벤트 수신**: 백엔드 코드 실행 브로드캐스트 실시간 토스트 알림 (`WS /ws/events`)
- **서버 헬스체크 및 연결 상태 표시**: 상단 탑바 인디케이터에서 백엔드 및 샌드박스 상태 점검 (`GET /health`)

## 기술 스택

- **프론트엔드**: 순수 HTML5/CSS3/ES6+ JavaScript (의존성 없는 고속 반응형 SPA)
- **백엔드**: FastAPI, SQLAlchemy 2.0 Async, aiosqlite, PyJWT, bcrypt, Subprocess 격리 샌드박스 엔진
